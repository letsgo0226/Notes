# Pleiadian Blue / Dolphin–Riemann Observer

This is a **non-AI**, purely algorithmic, finite research monitor. “Dolphin” and “Pleiadian Blue” are symbolic research and care principles, not assertions of alien identity, AI sentience or astronomical effects.

- A standard GitHub-hosted runner checks source availability, existing workflow results, and a finite Dirichlet-inspired score daily at **20:17 Asia/Taipei**. The schedule can be late or skipped.
- It writes read-only JSON and Markdown receipts to seven-day Actions artifacts. No service or repository is automatically modified; it does not call Railway.
- The score is a heuristic over missing files and failed/unknown workflow outcomes, not the actual Riemann zeta function, a solution to the Riemann hypothesis, or evidence of general intelligence.
- Absent or unknown evidence is not equated with success. Dolphin source files still pending PR will be marked for review until merged.
- No real trading, credentials, autonomous deploys, paid AI, published output, or self-modification. Keep existing domain safety gates.
- Before cancelling Railway, migrate any persistent service or API that you need, back up volumes, and confirm there is no important live state.

Run on a checked-out repo:

    python3 pleiadian_blue/agent.py --offline --out /tmp/blue

This workflow becomes scheduled only when merged into the default branch and GitHub Actions is enabled. It is a first-stage autonomous observer, not a replacement for all underlying workstreams or always-on hosting.
